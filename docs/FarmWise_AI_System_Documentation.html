1. FarmWise AI Advisor (Core Orchestrator & Conversational Agent)

Feature Overview

The FarmWise AI Advisor is the central coordinating brain of the entire platform. It functions as an agricultural expert system and bilingual conversational assistant that handles farmer inquiries via text, voice (Tamil & English), field photographs, or cadastral survey number selection. Rather than relying on a single AI model—which risks hallucinations or generic answers—it uses a multi-agent orchestrator that breaks down incoming requests, routes each sub-task to the most cost-effective and capable model, cross-verifies facts against scientific sources, and returns verified, parcel-specific advisories.

Tech Stack, APIs & Architectural Justification

  • FastAPI (Python 3.11): Asynchronous REST API server exposing POST /api/advisory/run and POST /api/chat, chosen for non-blocking I/O, rapid JSON serialization, and strict Pydantic schema validation.
  • LangGraph / Multi-Agent StateGraph (backend/app/agents/graph.py): Manages multi-agent execution loops using a strongly-typed shared state (AgentState). It coordinates sequential and parallel agent nodes with full step-by-step trace logging.
  • Multi-Model Routing Architecture (model_router.py):
    • Ministral 8B / 3B Instruct (AWS Bedrock, ap-south-1): Low-latency, low-cost open-weight model used for initial plan drafting, agricultural intent classification, query rewriting, and lightweight translation.
    • Gemini 1.5 Flash (Google Cloud API): High-speed multimodal vision model used for first-line crop photograph diagnostics, disease symptom detection, and Tamil voice audio transcription fallback.
    • Claude 3.5 Sonnet (Anthropic): Premier reasoning model acting as the autonomous Verifier & Critic Agent, auditing fertilizer dosages against soil chemistry and halting any hallucinated or unsafe recommendations.
  • RAG System (Amazon Titan Text Embeddings V2 + Vector Store): Performs semantic retrieval across verified Tamil Nadu Agricultural University (TNAU) Crop Production Guides and ICAR agronomic manuals.
  • Frontend Interface: React + Vite + Tailwind CSS + Web Speech API (ta-IN / en-IN) for real-time voice input and spoken advisory playback.

What the Feature Actually Did

  1. Ingests multi-modal farmer inputs: cadastral survey numbers, smartphone field photos, Tamil/English voice recordings, or free-text questions.
  2. Enforces an Agricultural-Only Domain Gatekeeper that politely refuses off-topic requests (e.g., politics, coding, jokes) while welcoming greetings and agriculture-linked finance/IoT questions.
  3. Maintains session memory (chat_history) and live parcel context (soil, weather, crop stage) across multi-turn conversations.
  4. Records live telemetry per step: model selected, token usage, latency (ms), confidence score, and scientific citations.

How It Works (Step-by-Step)

  1. Request Intake: Farmer submits a query (e.g., "When should I apply urea to my paddy field?") or selects survey number 1476.
  2. Intent Classification & Planning: planner.py verifies agricultural intent and builds an execution plan specifying which specialized agents are needed.
  3. State Hydration: AgentState is populated with registered parcel details, soil test profile, and recent weather observations.
  4. Parallel Agent Execution: Geo, Weather, Soil, and Image agents execute concurrently to gather real-time evidence.
  5. RAG Knowledge Retrieval: knowledge_agent.py retrieves exact TNAU/ICAR dosage and pest-control protocols matching the detected crop and growth stage.
  6. Verifier Safety Audit: verifier_agent.py (Claude 3.5 Sonnet) inspects the draft advisory for chemical incompatibilities, rainfall leaching conflicts, and dosage limits.
  7. Bilingual Delivery: Final verified advisory is returned as interactive UI cards, printable government reports, and Tamil/English voice readout.

2. Cadastral Parcel & FMB Boundary Mapping

Feature Overview

Bridges physical Tamil Nadu revenue land records with interactive digital GIS maps. It uses official Field Measurement Book (FMB) and Cadastral survey datasets covering 14,643 registered cultivation records across 21 villages in Tenkasi (Sivagiri taluk) and Thoothukudi districts.

Tech Stack & APIs Used

  • Backend Endpoints: GET /api/parcels/search?q={query}, GET /api/parcels/{survey_number}, and GET /api/admin/crop-monitoring/cadastral-boundaries.
  • Turf.js & GeoJSON: Performs point-in-polygon checks, parcel area calculations (Acres & Hectares), and geographic centroid extraction without needing an external GIS server.
  • React Leaflet + Esri World Imagery & OpenStreetMap: Mobile-responsive interactive map rendering cadastral parcel polygons over high-resolution satellite imagery.

How It Works (Step-by-Step)

  1. User enters or speaks a survey number (e.g., 1476, 386, 1342).
  2. geo_agent.py queries Ground_truth_Points.csv, Cadastral_Map_Final.geojson, and FMB_sample.geojson.
  3. The system computes polygon area, perimeter, and geographic centroid [latitude, longitude] to anchor weather forecasts and satellite views.
  4. PII landowner names are automatically masked in public/farmer views (e.g., Murugan S. → M****** S.) and revealed only in authorized officer views.

3. Ground-Truth Field Photo & 4. Crop Phenotype & Health Diagnostics

Feature Overview

Provides end-to-end handling of real smartphone field photographs: from secure upload and GPS EXIF authenticity verification to automated multimodal computer vision diagnosis of crop species, phenological growth stage, pest infestations, and nutrient deficiencies.

Tech Stack & APIs Used

  • API Endpoint: POST /api/upload (multipart streaming ingestion with client-side compression for low-bandwidth rural networks).
  • Python PIL / Pillow & ExifRead: Extracts embedded EXIF metadata (GPS latitude/longitude, capture timestamp, device orientation) to verify the photo was captured near the claimed survey parcel.
  • Private AWS S3 Storage (ap-south-1 Mumbai): Stores uploaded imagery privately with tracked hash keys (never exposed via public URLs).
  • Gemini 1.5 Flash Vision + Amazon Titan Multimodal Embeddings (Fallback): Analyzes leaf lesions, chlorosis, and canopy structure, returning strict Pydantic-validated JSON (CropAnalysis).

What It Outputs & How It Works

  1. Farmer captures or uploads a crop/leaf photo via the upload modal.
  2. image_agent.py validates EXIF GPS tags against the parcel boundary and passes the normalized image to Gemini 1.5 Flash with an agronomic taxonomy prompt.
  3. The model identifies: (a) Crop Variety (e.g., Rice/Paddy, Banana, Coconut, Maize, Cotton), (b) Growth Stage (Nursery, Tillering, Panicle Initiation, Flowering, Harvesting), (c) Detected Pathology (e.g., Rice Blast, Bacterial Leaf Blight, Brown Plant Hopper, Nitrogen Chlorosis), and (d) Health Score (0–100%) with confidence rating.

5. Micro-Climate & Agro-Meteorological Intelligence

Feature Overview & APIs

Translates raw hyper-local meteorological observations into actionable agricultural safety rules using GET /api/weather/parcel/{survey_number} backed by the keyless, open-access Open-Meteo REST API (https://api.open-meteo.com/v1/forecast).

How It Works & Agro-Met Rule Engine

  1. weather_agent.py extracts the parcel centroid [lat, lng] and fetches a 7-day hourly forecast plus 14-day rainfall history.
  2. weather_service.py evaluates operational rules that directly interlock with fertilizer and spraying schedules:
Rule 1 (Rain Leaching Alert): Forecast Rainfall (48h) > 15 mm ⇒ Trigger "Rain Leaching Warning" (Postpone Urea)
Rule 2 (Foliar Spray Window): Wind Speed < 15 km/h AND Rain Prob < 30% ⇒ "Safe Spraying Window"
Rule 3 (Fungal Pathogen Risk): Relative Humidity > 85% AND 24°C ≤ Temp ≤ 28°C ⇒ "High Blast / Blight Risk"

6. Soil Health & Chemical Profile (In-Depth Technical Breakdown)

Feature Overview

Evaluates chemical, biological, and physical soil properties at the parcel level, replicating the National Soil Health Card (SHC) scheme grounded in TNAU Soil Survey & Fertility Classification Guidelines.

Tech Stack & Key Metrics

  • Deterministic Soil Service (soil_service.py): Uses SHA-256 hashing anchored to survey numbers and TNAU agro-climatic zones so test parcels yield consistent, realistic soil profiles across sessions.
  • Measured Parameters: Soil Texture (Red Loamy, Calcareous Alkaline Loam, Black Cotton), Soil Reaction (pH), Electrical Conductivity (EC in dS/m), Organic Carbon (OC %), and Available Macronutrients (N, P2O5, K2O in kg/ha).
pH Penalty = |pH - 7.0| × 12.0  |  OC Boost = (Organic Carbon - 0.5) × 15.0
Fertilizer Uptake Efficiency Score = Clamp(85 - pH Penalty + OC Boost, 52%, 92%)

Scientific Basis & Amendment Decision Logic: In neutral soil (pH 6.8–7.2) with high OC (>0.75%), fertilizer uptake reaches ~88%. Above pH 8.0, phosphorus precipitates with calcium ions and urea volatilizes as ammonia gas, dropping uptake efficiency to 55%–62%.

  • Case 1 — Alkaline / Calcareous Soils (pH > 7.8): Apply Agricultural Gypsum (CaSO4·2H2O) @ 100 kg/acre to displace exchangeable sodium; grow green manure (Daincha / Sunnhemp @ 20 kg/acre); switch to Neem-Coated Urea in 3 splits + Zinc Sulphate (21%) @ 10 kg/acre.
  • Case 2 — Acidic Soils (pH < 6.3): Apply Agricultural Lime / Dolomite @ 120 kg/acre during preparatory tillage and use Rock Phosphate instead of acid-forming Ammonium Sulphate.
  • Case 3 — Low Organic Carbon (OC < 0.50%): Incorporate 5 MT/acre well-decomposed Farmyard Manure (FYM) or 2 MT/acre vermicompost to restore soil microbiology and Cation Exchange Capacity (CEC).

7. Personalised Agronomic Advisory & Multi-Agent Interlocks

Feature Overview

Synthesizes crop growth stage, soil chemistry, and 48-hour rainfall forecasts into a verified, stage-by-stage action schedule with exact dilution ratios and safety interlocks.

  • Dynamic Dosage Compensation: Replaces flat textbook fertilizer tables with soil-compensated dosages—automatically reducing DAP by 20% when available Phosphorus > 22 kg/ha, or prescribing SSP (100 kg/acre) when P < 12 kg/ha.
  • Bio-Fertilizer Integration: Co-inoculates Azospirillum + Phosphobacteria @ 2 kg/acre with 50 kg FYM, cutting synthetic chemical Nitrogen needs by 25%.
  • Weather-Conflict Verification Interlock: Cross-checks top-dress Urea against 48-hour rainfall forecasts (>15 mm), automatically shifting application to a "Post-rain window (24–48h after standing water drains)".

8. Seasonal Crop Recommendation & Profit Prediction Engine (Feature 2)

Feature Overview & APIs

Helps farmers identify the Top 5 most suitable and profitable seasonal crops for their specific parcel rather than blindly chasing high market prices without considering soil or cultivation costs.

  • APIs Used: GET /api/crop-recommendations, GET /api/crop-recommendations/{survey_number}/profit-analysis, GET /api/crop-recommendations/{survey_number}/market-trends, and GET /api/admin/crop-recommendations/analytics.
Suitability Score = (0.35 × Soil Match) + (0.25 × Weather & Water) + (0.25 × Net Profit Economics) + (0.15 × TNAU Seasonal Fit)
Estimated Net Profit (₹/acre) = (Expected Yield × Expected Agmarknet Modal Price) - Total Cultivation Cost

For each of the Top 5 ranked crops, the platform displays: Recommended Season, Sowing Period, Cultivation Duration, Soil & Weather Suitability, Water Requirement, Expected Yield/Acre, Cultivation Cost/Acre, Expected Selling Price, Gross Revenue, Net Profit, Recommendation Score, and a plain-language explanation.

Feature Overview & APIs

Equips agricultural officers with a real-time GIS surveillance dashboard spanning all 14,643 registered parcels across Tenkasi and Thoothukudi districts.

இந்த அம்சம் என்ன செய்கிறது?

FarmWise AI Advisor என்பது இந்த தளத்தின் "மைய மூளை" (Central Brain) ஆகும். ஒரு விவசாயி தனது நில சர்வே எண், பயிர் புகைப்படம் அல்லது தமிழ் குரல் மூலம் கேள்வி கேட்கும்போது, இந்த ஆலோசகர் ஒரே ஒரு AI மாதிரியை மட்டும் நம்பியிருக்காமல், பல்வேறு சிறப்பு துணை ஏஜென்ட்டுகளை (Sub-Agents) ஒருங்கிணைத்து இயக்கி, தவறுகளற்ற, அறிவியல் பூர்வமான வேளாண் ஆலோசனைகளை வழங்குகிறது.

பயன்படுத்தப்பட்ட தொழில்நுட்பங்கள் & APIகள்:

  • FastAPI (Python 3.11): அதிவேகமான மற்றும் தடையற்ற API (POST /api/advisory/run, POST /api/chat) பரிமாற்றத்திற்கு பயன்படுகிறது.
  • LangGraph / Multi-Agent StateGraph: பல AI ஏஜென்ட்டுகள் (Geo, Weather, Soil, Image, Knowledge, Verifier) ஒன்றுக்கொன்று தகவல்களைப் பகிர்ந்து செயல்பட உதவுகிறது.
  • Multi-Model Routing (பல-மாதிரி வழிசெலுத்தல்):
    • Ministral 8B / 3B (AWS Bedrock): குறைந்த செலவில் விரைவான திட்டமிடல், கேள்வி வகைப்படுத்தல் மற்றும் மொழிபெயர்ப்பு பணிகளுக்குப் பயன்படுகிறது.
    • Gemini 1.5 Flash (Google Cloud): பயிர் புகைப்படங்களை ஆராய்ந்து நோய் கண்டறியவும், தமிழ் குரல் பதிவுகளை உரையாக மாற்றவும் பயன்படுகிறது.
    • Claude 3.5 Sonnet (Anthropic): வழங்கப்பட்ட ஆலோசனைகளில் உர அளவுகள் மற்றும் அறிவியல் உண்மைகள் சரியாக உள்ளதா என சரிபார்க்கும் முதன்மை தணிக்கையாளராக (Verifier/Critic) செயல்படுகிறது.
  • Vector RAG (Amazon Titan Embeddings V2): தமிழ்நாடு வேளாண்மைப் பல்கலைக்கழகம் (TNAU) மற்றும் ICAR வழிகாட்டி கையேடுகளில் இருந்து துல்லியமான தகவல்களைத் தேடி எடுக்கிறது.

3. Ground-Truth Field Photo & 4. Crop Phenotype & Health (களப் புகைப்படம் & பயிர் நோய் ஆய்வு)

இந்த அம்சம் என்ன செய்கிறது & எவ்வாறு இயங்குகிறது?

விவசாயிகள் வயலில் எடுக்கும் பயிர் அல்லது இலைகளின் புகைப்படங்களை POST /api/upload மூலம் பதிவேற்றும்போது, Python PIL & ExifRead மூலம் படத்தில் உள்ள GPS இருப்பிடம் மற்றும் நேரம் சரிபார்க்கப்பட்டு, படம் அந்த சர்வே எண் நிலத்தில்தான் எடுக்கப்பட்டதா என்பது உறுதி செய்யப்படுகிறது. பின்னர் படம் Private AWS S3 (Mumbai)-ல் பாதுகாப்பாகச் சேமிக்கப்படுகிறது.

அதன்பின் Gemini 1.5 Flash Multimodal Vision படத்தை ஆய்வு செய்து: (1) பயிர் வகை (நெல், வாழை, தென்னை, மக்காச்சோளம், பருத்தி), (2) வளர்ச்சிப் பருவம் (நாற்று, தூர் கட்டும் பருவம், கதிர் உருவாகும் பருவம், அறுவடை), (3) பூச்சி அல்லது பூஞ்சாண நோய்கள் (புகையான், இலைக்கருகல், இலைப்புள்ளி) மற்றும் (4) பயிர் ஆரோக்கிய மதிப்பெண் (0–100%) ஆகியவற்றைத் துல்லியமாகக் கண்டறிகிறது.

5. Micro-Climate & Agro-Met (நுண் வானிலை & வேளாண் எச்சரிக்கைகள்)

GET /api/weather/parcel/{survey_number} மற்றும் இலவச Open-Meteo REST API மூலம் நிலத்தின் மையப்புள்ளிக்குரிய நேரடி 7-நாள் வானிலை முன்னறிவிப்பு மற்றும் 14-நாள் மழைப் பதிவைப் பெறுகிறது.

1. மழை உரம் இழப்பு எச்சரிக்கை: அடுத்த 48 மணி நேரத்தில் 15 மி.மீ-க்கு மேல் மழை பெய்தால் யூரியா மேலுரமிடுவதைத் தள்ளிப்போட எச்சரிக்கும்.
2. மருந்து தெளிக்கும் நேரம்: காற்றின் வேகம் 15 கி.மீ/மணிக்கு குறைவாகவும் மழை வாய்ப்பு 30%-க்கு கீழும் இருந்தால் பாதுகாப்பான நேரம் எனக் காட்டும்.
3. பூஞ்சாண நோய் எச்சரிக்கை: ஈரப்பதம் 85%-க்கு மேலும் வெப்பநிலை 24–28°C ஆகவும் இருந்தால் குலைநோய் (Blast / Blight) எச்சரிக்கை வழங்கும்.

6. Soil Health & Chemical Profile (மண்வளம் மற்றும் ஊட்டச்சத்து பகுப்பாய்வு — ஆழமான விளக்கம்)

தமிழ்நாடு வேளாண்மைப் பல்கலைக்கழக (TNAU) மண் ஆய்வு நெறிமுறைகள் மற்றும் தேசிய மண்வள அட்டைத் திட்டத்தின் (SHC) அடிப்படையில் மண்ணின் வகை, கார-அமிலத்தன்மை (pH), கரிமக் கரிமம் (OC), உவர்தன்மை (EC) மற்றும் தழை, மணி, சாம்பல் சத்துக்களை (NPK) ஆய்வு செய்கிறது.

  • உர பயன்பாட்டுத் திறன் (Fertilizer Uptake Efficiency): நடுநிலையான மண்ணில் (pH 6.8–7.2) உர ஏற்புத்திறன் 88% வரை இருக்கும். ஆனால் மண் காரத்தன்மையுடன் (pH 8.2) இருக்கும்போது மணிச்சத்து சுண்ணாம்புடன் பிணைக்கப்பட்டு வீணாவதால் உர ஏற்புத்திறன் 62% ஆகக் குறைகிறது.
  • மண் காரத்தன்மை (pH > 7.8): ஏக்கருக்கு 100 கிலோ வேளாண் ஜிப்சம், தக்கைப்பூண்டு பசுந்தாள் உரம் (20 கிலோ/ஏக்கர்), வேப்பம்பூசப்பட்ட யூரியா (3 தவணைகள்) மற்றும் துத்தநாக சல்பேட் (10 கிலோ/ஏக்கர்) இடப் பரிந்துரைக்கப்படுகிறது.
  • மண் அமிலத்தன்மை (pH < 6.3): ஏக்கருக்கு 120 கிலோ வேளாண் சுண்ணாம்பு (டாலமைட்) மற்றும் ராக் பாஸ்பேட் இடப் பரிந்துரைக்கப்படுகிறது.
  • கரிமக் கரிமம் குறைவு (OC < 0.50%): ஏக்கருக்கு 5 டன் மக்கிய தொழுவுரம் (FYM) அல்லது 2 டன் மண்புழு உரம் இடுவது அவசியமாக்கப்படுகிறது.

7. Personalised Agronomic Advisory (தனிப்பயனாக்கப்பட்ட வேளாண் ஆலோசனை)

knowledge_agent.py மற்றும் verifier_agent.py (Claude 3.5) இணைந்து ஒவ்வொரு நிலத்திற்கும் தனித்துவமான செயல் திட்டத்தை உருவாக்குகின்றன:

  • மண் நிலைக்கு ஏற்ப உர அளவு மாற்றம்: மண்ணில் மணிச்சத்து அதிகமாக இருந்தால் (>22 கிலோ/ஹெக்டேர்), இரசாயன DAP உரத்தின் அளவை 20% குறைத்து விவசாயியின் செலவை மிச்சப்படுத்துகிறது.
  • உயிர் உரங்கள் சேர்த்தல்: அசோஸ்பைரில்லம் மற்றும் பாஸ்போபாக்டீரியா தலா 2 கிலோவை 50 கிலோ தொழுவுரத்துடன் கலந்து இடப் பரிந்துரைப்பதன் மூலம் இரசாயன தழைச்சத்துத் தேவையை 25% குறைக்கிறது.
  • வானிலை முரண்பாடு சரிபார்ப்பு (Weather Interlock): அடுத்த 48 மணி நேரத்தில் 15 மி.மீ-க்கு மேல் மழை பெய்யும் வாய்ப்பிருந்தால், யூரியா மேலுரமிடும் தேதியைத் தானாகவே "மழை நீர் வடிந்த பிறகு 24–48 மணி நேரம் கழித்து இடவும்" என மாற்றியமைக்கிறது.

8. பருவகால பயிர் பரிந்துரை & லாப கணிப்பு (Feature 2)

GET /api/crop-recommendations, /profit-analysis மற்றும் /market-trends APIகள் மூலம் விவசாயியின் நிலத்திற்குத் தற்போதைய பருவத்தில் (கார், குருவை, நவரை) அதிக மகசூலும் நிகர லாபமும் தரக்கூடிய சிறந்த 5 மாற்றுப் பயிர்களை வரிசைப்படுத்துகிறது.

வெறும் சந்தை விலை உயர்வை மட்டும் பார்க்காமல், மண் பொருத்தம் (35%) + வானிலை & நீர் வசதி (25%) + நிகர லாபம் (25%) + TNAU பருவப் பொருத்தம் (15%) ஆகியவற்றைக் கணக்கிட்டு, ஏக்கருக்கான சாகுபடி செலவு, எதிர்பார்க்கப்படும் மகசூல், e-NAM/Agmarknet விற்பனை விலை மற்றும் நிகர லாபம் (Net Profit) ஆகியவற்றைத் தெளிவான விளக்கத்துடன் வழங்குகிறது.

9. அரசு அதிகாரி GIS கண்காணிப்பு & ஸ்மார்ட் முன்னுரிமை வடிகட்டிகள் (Feature 3)

தென்காசி மற்றும் தூத்துக்குடி மாவட்டங்களின் 14,643 நிலப் பதிவேடுகளை அரசு அதிகாரிகள் கண்காணிக்கவும், கள ஆய்வு செய்து அங்கீகரிக்கவும் உதவுகிறது (GET /api/admin/crop-monitoring/markers, /records, PUT /records/{id}).

  • முன்னுரிமைப் பிரிவு (Priority Classification):
    • HIGH (உயர் முன்னுரிமை): பயிர் ஆரோக்கியம் 50%-க்குக் குறைவாக உள்ளவை அல்லது பூச்சி/நோய் தாக்குதல் உறுதி செய்யப்பட்டவை.
    • MEDIUM (நடுத்தர முன்னுரிமை): ஆரோக்கியம் 50–79% உள்ளவை, தரவு இல்லாதவை அல்லது சரிபார்ப்பு நிலுவையில் உள்ளவை.
    • LOW (குறைந்த முன்னுரிமை): ஆரோக்கியமான (80–100%) மற்றும் சரிபார்க்கப்பட்ட நிலங்கள்.
  • வரைபடம் & அட்டவணை ஒருங்கிணைப்பு: Stratified Sampling மூலம் 12 பயிர்களின் எமோஜி சின்னங்களும் (🌾, 🥥, 🌽, 🍌, 🎋) செயற்கைக்கோள் வரைபடத்தில் ஒரே நேரத்தில் காட்டப்படுகின்றன. சரிபார்ப்பு வடிகட்டியில் Verified, Verification Required, Rejected, Not Verified ஆகிய 4 நிலைகள் உள்ளன, மேலும் அட்டவணையில் உள்ள "Map" பொத்தான் குறிப்பிட்ட நிலத்தை நேரடியாக வரைபடத்தில் காட்டுகிறது.

கூடுதல் முக்கிய அம்சங்கள் அட்டவணை

கூடுதல் அம்சம் பயன்படுத்தப்பட்ட தொழில்நுட்பம் / API என்ன செய்கிறது & எவ்வாறு இயங்குகிறது?
இருமொழி குரல் உதவியாளர் (தமிழ் & ஆங்கிலம்) Web Speech API + POST /api/voice/transcribe விவசாயிகள் மைக்ரோஃபோன் பொத்தானை அழுத்தி தமிழில் பேசலாம். Gemini Audio மூலம் உரையாக மாற்றப்பட்டு, AI ஆலோசனை தமிழில் குரலாக வாசிக்கப்படும்.
அரசு மாதிரி அச்சு அறிக்கை (Printable Report) HTML Print CSS + QR Code நில வரைபடம், பயிர் நிலை, மண் அட்டை மற்றும் ஆலோசனைகளை அரசு அதிகாரிகள், பயிர் காப்பீடு மற்றும் வங்கி கடன் பெறுவதற்கு ஏற்ற ஆவணமாக அச்சிட்டுத் தருகிறது.
நேரடி சந்தை (APMC Mandi) விலை நிலவரம் GET /api/market/prices (e-NAM / Agmarknet) அருகிலுள்ள சந்தைகளில் (தென்காசி, திருநெல்வேலி, மதுரை) விளைபொருட்களின் இன்றைய குறைந்தபட்ச, அதிகபட்ச மற்றும் சராசரி விற்பனை விலையைக் (₹/குவிண்டால்) காட்டுகிறது.
விவசாயி தரவுப் பாதுகாப்பு (PII Masking) privacy_service.py பட்டாதாரரின் தனிப்பட்ட பெயர்களை மறைத்து (எ.கா: M****** S.) பாதுகாப்பாக வைக்கிறது; அதிகாரிகள் உள்நுழையும் போது மட்டுமே முழு விவரமும் தெரியும்.
